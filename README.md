# Sistema de Registro de Tareas

Este proyecto fue desarrollado como trabajo práctico, con el objetivo de crear un sistema CRUD sencillo para el registro de tareas de alumnos.

La aplicación fue realizada completamente en frontend, utilizando HTML, CSS personalizado y JavaScript.

El sistema permite registrar una tarea ingresando su nombre y descripción, visualizar las tareas cargadas, editarlas, eliminarlas y realizar búsquedas dentro del listado.

También se implementó LocalStorage para que los datos queden guardados en el navegador y no se pierdan al actualizar o cerrar la página.

## Funcionalidades

- Registrar tareas
- Listar tareas
- Editar tareas
- Eliminar tareas
- Buscar tareas
- Validar campos del formulario
- Guardar información mediante LocalStorage
- Diseño responsive y profesional

## Tecnologías utilizadas

- HTML5
- CSS
- JavaScript
